TikTok API Integration

How we use TikTok's API

Nova Fit AI uses TikTok's Content Posting API exclusively to publish pre-produced fitness videos to the authorized creator account (@iamnova.fit). We do not collect data from viewers, engage in scraping, or interact with any account other than the one explicitly authorized by the account owner.

All content is pre-produced and reviewed before posting. The API is used solely for video upload and scheduling — no user data beyond the creator's access token is stored.

📤
video.upload / video.publish
Used to upload AI-generated fitness videos and publish them to the @iamnova.fit TikTok account on a scheduled basis. No other accounts are accessed.
👤
user.info.basic
Used to verify the authorized account identity before posting. No viewer or follower data is accessed or stored.
